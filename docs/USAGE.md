# 使用說明

## 查詢目前位置的樁號

按「定位樁號」並允許瀏覽器取得位置，或直接點選地圖。查詢會自動判斷附近道路；遇到道路交會或重疊時，可從結果中選擇道路。

「顯示GPS藍點」可持續顯示所在位置，但不會自動查詢樁號。移動後需要再次查詢時，請按「定位樁號」。

## 貼上座標、樁號或路段

在「貼上位置、樁號或路段」欄位輸入文字，再按「辨識並定位」。可貼整段文字，或使用下列寫法：

| 輸入範例 | 查詢內容 |
| --- | --- |
| `22.49,120.62` | 經緯度，緯度在前、經度在後 |
| `X 195183.575 Y 2506266.517` | TWD97／121°分帶座標 |
| `台27線59K+223` | 單一樁號位置 |
| `縣185 34.544 到 35.200` | 34K+544 至 35K+200 的路段 |
| `台27線59K+223 順樁150公尺` | 從 59K+223 到 59K+373 |
| `台27線59K+223 逆樁150公尺` | 從 59K+223 到 59K+073 |
| `台1線392K+406（順樁向）` | 樁號位置與順樁向側別示意 |

辨識出多個位置或路段時，可逐一選擇，也可按「全部標記在地圖」。

順樁代表里程增加，逆樁代表里程減少。附有距離時表示路段；未附距離時表示道路側別。側別標示僅供示意，不代表實際車道位置。

## 手動輸入

展開「手動選擇」，可分別輸入 TWD97 座標、道路與單一樁號、起迄里程，或順逆樁範圍。

查詢單一樁號時，公里與公尺兩欄都留白，會定位到該道路資料中的最小里程。只留一欄空白時，該欄以 0 計算。

## 地圖、分享與匯出

- 底圖可選「街道圖」、「正射影像」或「影像＋路名」。
- 按「參考線」可載入目前畫面內的道路參考線。
- 單點查詢結果可開啟 Google Maps 或複製位置連結；連結使用原樁號位置，不包含側別示意的偏移。
- 電腦版可從地圖上的「匯出」選單下載 JPG 或 PNG 圖片，手機版不顯示此選單。

## 資料範圍

「道路資料範圍與缺口」可查看各道路的起迄里程與無法連續標示的區間。查詢結果會註明推估、資料缺口或超出範圍等情況。

里程差與圖上估算長度不等於實際施工或管道長度。樁號與位置供定位參考，仍應以現地資料為準。
