# 使用說明

## 查詢目前位置的樁號

按「定位樁號」並允許瀏覽器取得位置，或直接點選地圖。查詢會自動判斷附近道路；遇到道路交會或重疊時，可從結果中選擇道路。

「顯示GPS藍點」可持續顯示所在位置，但不會自動查詢樁號。移動後需要再次查詢時，請按「定位樁號」。

## 貼上座標、樁號或路段

在「貼上位置、樁號或路段」欄位輸入文字，再按「辨識並定位」。欄位有文字時，右上角的「×」可一鍵清除內容與辨識結果。可貼整段文字，或使用下列寫法：

| 輸入範例 | 查詢內容 |
| --- | --- |
| `22.49,120.62` | 經緯度，緯度在前、經度在後 |
| `X 195183.575 Y 2506266.517` | TWD97／121°分帶座標 |
| `台27線59K+223` | 單一樁號位置 |
| `縣185 34.544 到 35.200` | 34K+544 至 35K+200 的路段 |
| `台27線59K+223 順樁150公尺` | 從 59K+223 到 59K+373 |
| `台27線59K+223 逆樁150公尺` | 從 59K+223 到 59K+073 |
| `台1線392K+406（順樁向）` | 樁號位置與順樁向側別示意 |
| `台27線59K+223 順樁1.5公里` | 從 59K+223 到 60K+723 |
| `22°29'24"N 120°37'12"E`、`N22.49 E120.62` | 度分秒或標示 N／E 的經緯度 |

辨識出多個位置或路段時，可逐一選擇，也可按「全部標記在地圖」。

## 查詢紀錄

查過的樁號、路段與多點標記會記在輸入框下方的「查詢紀錄」，預設收起；展開後點一筆即可重新查詢。紀錄只存在目前這個瀏覽器，最多 20 筆，重複的位置只留最新一筆，可按「清除紀錄」全部刪除。直接點選地圖的查詢不列入。

順樁代表里程增加，逆樁代表里程減少。附有距離時表示路段；未附距離時表示道路側別。側別標示僅供示意，不代表實際車道位置。

## 手動輸入

展開「手動選擇」，可分別輸入 TWD97 座標、道路與單一樁號、起迄里程，或順逆樁範圍。

查詢單一樁號時，公里與公尺兩欄都留白，會定位到該道路資料中的最小里程。只留一欄空白時，該欄以 0 計算。

## 管養工務段與鄉鎮村里

省道（台1、台3、台9、台17、台22、台24、台26、台27、台88 等）的查詢結果會顯示管養工務段與鄉鎮村里，依公路局里程牌資料取前後最近的里程牌；若前後里程牌分屬不同村里或工務段，會兩者並列，表示位於交界路段。縣道與鄉道沒有此資料。

## 地圖、分享與匯出

- 底圖可選「街道圖」、「正射影像」或「影像＋路名」。
- 按「參考線」可載入目前畫面內的道路參考線。
- 單點查詢結果的「導航」會開啟 Google Maps，使用原樁號位置，不包含側別示意的偏移。
- 「複製連結」複製一行說明文字與本網站的短連結，例如：

  ```
  台1線 約392K+406（順樁向側）
  https://licni.github.io/show_me_the_miles/?s=T1_392406f
  ```

  對方開啟後會看到同一個樁號、路段或多點標記（含側別示意）。路段結果與「地圖標記」清單也有這個按鈕；多點標記會逐行列出各位置。
- 「複製文字」複製道路與樁號、管養工務段與鄉鎮村里、經緯度及 TWD97 座標，可直接貼到通訊軟體或文件。
- 電腦版可從地圖上的「匯出」選單下載 JPG 或 PNG 圖片。
- 手機版按地圖左下角的「分享圖片」，會產生 JPG 並開啟系統分享選單；若出現「點此分享」請再按一次，瀏覽器不支援分享時改為下載。

## 資料範圍

「道路資料範圍與缺口」可查看各道路的起迄里程與無法連續標示的區間。查詢結果會註明推估、資料缺口或超出範圍等情況。

里程差與圖上估算長度不等於實際施工或管道長度。樁號與位置供定位參考，仍應以現地資料為準。
