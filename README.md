# show_me_the_miles

屏東地區的道路樁號查詢工具，支援省道、縣道與鄉道。

**[開啟樁號查詢網站](https://licni.github.io/show_me_the_miles/)**

## 功能

- 用 GPS 定位、地圖點選，或輸入 TWD97 座標、經緯度查詢樁號。
- 輸入樁號找位置，標示指定路段與順、逆樁向道路側別。
- 同時標記多個位置或路段，查看道路參考線。
- 切換一般地圖、正射影像與影像加標籤底圖。
- 開啟 Google Maps 導航或分享位置。
- 電腦版可匯出 JPG、PNG 圖片。

查詢結果供定位參考，實際樁號及位置請以現地資料為準。

資料依政府公開資訊整理。
